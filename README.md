# 📚 Key Learnings

This internship helped me develop practical understanding of the complete data analytics workflow.

### 1. Data Cleaning

I learned that reliable analysis starts with reliable data. I practiced identifying missing values, duplicates, inconsistent data, incorrect data types, and other quality issues before performing analysis.

### 2. Exploratory Data Analysis

I learned how to explore datasets systematically and identify patterns, trends, relationships, and unusual observations.

### 3. SQL for Business Analysis

I learned how SQL can be used to transform raw data into meaningful business information through filtering, grouping, aggregation, and analytical queries.

### 4. Power BI & Data Visualization

I gained practical experience in creating interactive dashboards, developing KPIs, using DAX, and presenting information in a way that supports business decisions.

### 5. Statistical Thinking

I learned how hypothesis testing can be used to validate observations and distinguish between assumptions and statistically supported conclusions.

### 6. Data Storytelling

I learned that data analysis is not only about finding numbers. It is also about communicating those findings clearly and connecting them to business questions.

### 7. End-to-End Analytics Workflow

Most importantly, I learned how different analytics techniques connect together:

**Raw Data → Cleaning → Exploration → SQL → Visualization → Statistical Validation → Insights → Business Story**
